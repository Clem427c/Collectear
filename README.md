# Collectear

Explore. Débloque. Collectionne.

Jeu mobile Flutter : des runs de 2 minutes dans un monde infini généré procéduralement,
pour collectionner 300 créatures et héros originaux.

- **Jouer (web)** : https://clem427c.github.io/Collectear/
- **APK Android** : https://github.com/Clem427c/Collectear/releases/latest/download/collectear.apk
- Design : [`docs/`](docs/) · Avancement : [`ROADMAP.md`](ROADMAP.md) · Versions : [`CHANGELOG.md`](CHANGELOG.md)

Contrôles clavier : ZQSD / WASD / flèches pour bouger, Espace = saut, J = attaque, K = esquive.
